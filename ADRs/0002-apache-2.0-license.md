# ADR-0002: Apache License 2.0

- Status: Accepted
- Date: 2026-07-15
- Scope: UniArchive

## Decision

UniArchive is Apache-2.0, which grants an explicit patent license alongside the
copyright permissions. The repo is author-single, so the licensing is
unambiguous. `NimContracts` is MIT and keeps its upstream terms.

`LICENSE`, `NOTICE` and `CONTRIBUTING.md` (DCO sign-off) ship with the repo.
`NOTICE` contains only the legally required notices for material actually
distributed by the repository.
